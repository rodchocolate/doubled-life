agents

Hermes — the agent system

Hermes is the email-driven local-LLM agent system. An IMAP IDLE daemon watches a mailbox; a recognized subject token fast-paths to a skill, anything else falls through to the research pipeline. An async worker drains jobs off disk (isolating iCloud open() wedges), a write-gate/policy layer bounds what agents may touch, and every action is audit-logged. Skills include: drop (email → live Shopify/Printify product), music/playlist/soundtrack (curated sets), video (prompt → Wan 2.2), image (prompt → Z-Image Turbo), darkside (themed story/scene sets), digest, and order (a two-step money gate).
