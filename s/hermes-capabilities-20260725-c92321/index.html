EXECUTIVE SUMMARY: HERMES

Hermes is a local-first LLM agent system hosted on a Mac Studio, designed to operate via an "Email-as-API" pattern. By utilizing local models via Ollama, it allows the user to trigger complex studio workflows from any device without exposing the system to the public internet. The system prioritizes data privacy and zero-cost execution by keeping all processing and data on-device.

System Architecture

Hermes is built to decouple intake from execution to prevent system "wedges" (specifically those caused by macOS TCC/external volume access). The pipeline operates as follows:

  • Email Intake: A `launchd` daemon monitors a Gmail account via IMAP IDLE. To ensure reliability, the daemon enqueues raw `.eml` files to the internal SSD, where a separate Async Worker drains the queue and dispatches tasks.
  • Local LLM Layer: Processing is handled by Ollama, utilizing models such as Gemma 4 (31B and e4b) and Mistral-Nemo (12B).
  • Skills & Execution: Tasks are routed to "Skills"—Python modules that execute specific logic (e.g., metadata extraction or API calls).
  • Write-Gate & Audit Log: To protect the system, a Write-gate (`policy/write_gate.py`) must be called by skills to validate destination paths before any write operation. Every gate decision and processed email is recorded in a canonical Audit Log (`actions.jsonl`).

Email Command Tokens

Hermes dispatches actions based on subject line tokens. Supported tokens include:

  • `drop`: Triggers product deployments.
  • `discover`: Executes `yt-dlp` for metadata and distilled note creation.
  • `prototype`: Adds tiles to the iamtoxico scratch board.
  • `remove`: Deletes specific tiles by title.
  • `digest`: Summarizes the body/links or provides a rollup of recent research notes.
  • `order`: A two-step money gate for creating and submitting Printify orders.
  • `research` / `recall`: Emails without specific tokens (or those explicitly marked for research) fall into the research queue for deeper processing.
  • `capsule`: (Supported dispatch token).

Current Capabilities

  • Instant Printify Drops: Hermes can transform email designs into live, buyable products on the iamtoxico store, automating the deployment of product grids and metadata.
  • TikTok & Video Transcription: A dedicated pipeline uses `yt-dlp` for audio extraction, `mlx-whisper` for transcription, and Gemma 4 (31B) to extract product and tool leads.
  • Research Pipeline & Doubled.life: Hermes manages an automated research workflow that populates doubled.life, a gated research site. This includes the generation of unlisted subject pages and a secure 1FA authentication gate with iMessage and Gmail SMTP code delivery.
