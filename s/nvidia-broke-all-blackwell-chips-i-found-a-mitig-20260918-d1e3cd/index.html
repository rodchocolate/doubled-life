summary

The video discusses a performance issue with NVIDIA Blackwell chips up until the driver update, where speculative decoding (MTP) is broken. The creator claims that setting the MTP draft depth to one allows for a significant speedup in LLM inference speed compared to the current broken state of the current drivers. He suggests using Vulkan instead of CUDA for those who want it to avoid this issue entirely.
