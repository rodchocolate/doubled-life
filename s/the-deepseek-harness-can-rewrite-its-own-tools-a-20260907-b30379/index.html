summary

The video explains the architecture of AI coding agents, using the DeepSeek Harness as a catalyst to discuss how 'harnesses' (like Claude Code or Cursor) manage the loop between a user's request, tool calls (reading/writing files), and LLM API responses. It emphasizes that an agent is essentially a combination of a model, a tool registry, a prompt assembly, and session management.
