I've recently been experimenting with a new platform called brick

for my animations.

I used it to create this interactive nested portal effect.

Brick is a platform where you can create your own interactive

visual tools using text prompts.

There are already many tools available in the tools gallery,

but I wanted to create something specifically for my own animations.

So I described my idea in the chat

and asked brick to generate a cursor controlled portal effect

for images and videos. Here

I can upload my own photo or video

and control the effect in real time.

I can experiment with the available settings,

change the size, speed,

and other parameters.

If I want to modify the effect or add a new control,

I can simply describe the change in the chat.

Once the result is ready, I can choose the output format,

set the video duration, and export it.

You can also explore tools created by other users in the gallery

and remix them for your own visuals.

What I really like about brick

is that you can turn a simple idea into a fully interactive

and customizable visual tool.
